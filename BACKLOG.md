- [x] ~~**Common schema for flashcard/facts, importable from git repos into learn_me.**~~ The JSON `DeckDocument` interchange is the schema. **Resolved 2026-10-10:** the root [`manifest.json`](manifest.json) is now part of the learn_me pack spec — the inventory an app that registers a pack endpoint reads (which packs, under what license, by `subject`/`tags`/`age`). Shape locked by `manifest.schema.json`; generated by the pack builder (`--manifest`), so it never drifts from the packs (a bare `deck` field would not have been enough — apps need license + subject + tags + age to gate imports). Open remains: the git-repo-as-pack-source *consumer* side (an app fetching the manifest + packs from a repo/endpoint URL) — that lands in `learn_me_core` with the tools residency move.

A future pass could pull the official answer book's rationale onto each option, and grade partial credit (3/1) where the source grades non-optimal but not-wrong answers.

- [] **RDF-backed facts (ingest from ORM/OWL/other RDF → pack).** *"eventually I suspect I'll want to lean hard into RDF (that's where learn_me started after all)."* New scope 2026-10-10: **fetch open RDF** (e.g. Monarch/UBERON skeletal anatomy) and convert to packs, carrying FOSS license + provenance. Decision open on both axes:
  - **Where it lives — RESOLVED 2026-10-10:** in core, as the `rdf-owl` adapter beside `fcc-pool`/`anki` (`packages/pack-builder/`). The no-RDF engine rule was released for tooling (it was a guide, not a gate); the adapter fetches OLS JSON and carries no RDF library.
  - **License carry:** UBERON is **CC-BY-3.0** (confirmed) — *not* ShareAlike, so a derived pack can be released under CC0 with attribution. Required: attribution + indication of changes + no-added-restrictions; CC0-derivative is the standard permitted path. The schema already carries this (`source_license` at deck level; `source`/`provenance` per card) — the pack builder now emits it.
  - **Monarch caveat:** "the Monarch system" licenses per-dataset (Monarch recommends CC0/CC-BY-4.0, but upstream sources vary) — need a per-source license check, not a blanket assumption. UBERON itself is clean CC-BY-3.0.
  - **Status 2026-10-10:** `rdf-owl` adapter **built + verified** (8 confirmed bones → 34 distinct "X is part of Y" cards, license carried; committed `6a22b6c`). **Open:** emit the actual `skeleton.json` pack — the curated human-bone IRI list still needs resolving (OLS search is slow/rate-limited; the one-off `resolve_bones.dart` resolver got stuck and was removed). Next: resolve the bone list (smaller batches / longer timeout / cache), build the pack, verify, commit.
